طريقة الحصول على ملف APK:
1) أنشئ حساب GitHub مجاني ثم مستودع جديد (New repository)، وارفع كل محتويات هذا المجلد (بما فيها مجلد .github).
2) افتح تبويب Actions، ثم build، ثم Run workflow. انتظر نحو 10 دقائق.
3) بعد انتهاء البناء، افتحه ونزّل remoty-apk من قسم Artifacts. هذا ملف التطبيق.
4) انقل الملف للتليفون وثبّته (اسمح بالتثبيت من مصدر غير معروف).
